# CMG 2022 Research Harness

[Download the ZIP](https://github.com/mochaccinowww-glitch/cmg2022-harness/releases/download/v0.4.1/cmg2022-harness-v0.4.1.zip), extract it and open the folder containing `AGENTS.md` in Codex. Give it a CMG project path or attach a model file:

> Read the attached DAT. Does the producer target oil or total liquid? List the BHP limits and leave the model unchanged.

A DAT describes requested controls. Supply the matching OUT or SR3 to check which control actually operated. For use in another project, copy `skills/cmg2022-harness` into its `.agents/skills/` folder and reopen the project. The full bundle includes the Python CLI for saving and resuming study context.
