# 把研究者的反馈转成可复算的工程记录

|研究者的说法|先核对什么|具体交付|
|---|---|---|
|“先评价，暂时不跑”|决策、可辨别的假设、已有对照|列出能复用的算例、最小补算、支持与推翻假设的观测；停在设计审阅。|
|“这个井在结果里消失了”|用户打开的确切文件、软件版本、时间帧、井状态和显示筛选|以交付副本从同一入口验证，记录井史与界面表现；有日志时保留警告原文。|
|“现场的曲线也这样吗”|同一井或井组、相态、分离条件、日历窗、实测点和作者计算线|同口径对照图及残差。公开曲线数字化记录读图误差；积分注明插值与端点处理。|
|“这个压力曲线为何恒定”|实达井控、限值、控制切换、参考深度|分别列井底流压、同深度井块压力、完井压差及实产量；强制输入仅作执行核验。|
|“图上看起来突破更早”|变量是总组成、气相饱和度还是产出气组分；帧间隔和实际注入量|给出首次事件区间及对应剂量，再看来源回采、波及和有参照的增油。|
|“目前最新版是哪份”|已确认的决策、选定角色与版本谱系|返回当前角色、ID、理由与文件；发现交付标题或重建脚本滞后时同时修正生成源。|

保留用户认可的表达和操作习惯时，注明它适用的项目或交付对象。给同事交接，附输入差异、复算命令和未决项；给导师汇报，正文选最能回答问题的一张图，把完整对照放在可追溯的附件。累计偏差较小但前后残差抵消时，两件事实一起交代。

**例。** 目标井的气油比升高可以促使研究者检查产出气组成、活动完井和实际产油量。如果要主张井组驱替效率下降，应再比较相同时间和实际注入剂量下的来源气回采、波及或配对增油。证据只支持提前到达时，把结论停在到达时序。时窗、阈值、井数和裂缝方向由当前研究资料决定。
