# CMG 2022 软件验收

| 应用 | 在实际工作站上验证 | 随案保存 |
|---|---|---|
| WinProp | 记录具体版本和 EOS，保留原始与归一化组成。分别验证原生编辑器打开、计算结束和给 GEM 使用的导出文件。核对组分次序、单位、分离条件及拟合残差。 | 输入、计算日志、实测与模拟偏差表。原生工程与 GEM 流体段分别命名。 |
| GEM | 从同一初态派生。逐项核对 INCLUDE、完井与井角色、注入流股、标准或地下体积、井控限制。先用短算例检查实际控制，再核查长期结果的终止日、警告、切步、求解失败、全局与关键组分物衡。 | 输入及包含文件、OUT、SR3、控制台日志、运行命令、版本和单位。 |
| Results | 打开交付的具体 SR3，核对井名、变量、相别、层位、输出时刻。PVT、网格流体物性和相图绘图对象分别检查。确认停井前后时间窗的井显示。 | 原生工程加数据源映射；用 Export Image 导出，逐条核图例。场图对照固定层位、帧时、色标和视角；派生图另标来源。 |
| CMOST | 确认本机版本、原生研究能否打开、作业如何提交。记录参数范围、目标函数、权重、阶段和原生排名；从对应 SR3 复算误差。CLI 支持以安装版本为准。 | 研究设置、原生排名、候选与母体映射、独立评分。 |

进程退出码、OUT 正常终止和 SR3 到达预期末日分别核查。读取不到面通量时登记缺项；需要该量的比较在派生案补输出。对原生图明确“打开何文件，哪个菜单，可见何对象”，用软件实际重开验证。命令行通过无法证明 GUI 兼容。
