# 证据与判据

1. 参数逐项标来源：实测、论文图读、作者公开拟合线、合成假设或模拟输出。记录单位、参考深度、相别、计量条件、有效时间。图读误差和原始气样缺失会限制单井结论。
2. 算例先写一个可检验的问题，指定母体、唯一预期改动、保持相同的条件及会随井控自行变化的量。逐一核对源文件差异和实际注采量。改变井角色同时改变近井能力时要说明归因范围。
3. 率控时以压力或其他独立响应比较；定压时以分相产量、组成等比较。实际生效的井控优先读原生状态；推断时写出容差。恒定的受控 BHP 不能用于提取压力扰动。
4. 历史拟合同时报告同期点误差和累计量，检查前后偏差抵消。已知公开曲线上的选模属于回顾性评价。用组量约束单井分配时注明假设。
5. 研究气窜时分别记录生产井 CO₂ 富集、地下游离气到达、来源明确的注入气回采。对低效循环另查同剂量及同历时下的配对增油或波及变化；模型时间步和网格敏感性可能大于组间差值。
6. 结果验收分三层：工程文件可用、物理解释有证据、事件标签可重复。事件发生在两空间帧之间时记录区间，随访结束未见事件保留右删失。机器学习按独立地质实现或井组拆分，配对算例与同一轨迹的不同截断同组；决策时刻以后的响应不得进入输入。
